# 💰 Spend Wise

A Python-based personal finance tracker that helps users record, organize, and analyze your daily expenses.

The functions of the Finance Tracker are :
1. Add Expense
2. View Expenses
3. Search Expense
4. Monthly Summary
5. Category Analysis
6. Budget Tracker
7. Savings Report
8. Edit Expense
9. Delete Expense
& Much More

> 🚧 This project is currently under development.
